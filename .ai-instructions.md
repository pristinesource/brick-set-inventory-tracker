## 🏗️ Architecture Guidelines

### Technology Stack
- **Framework**: Angular 17+ with standalone components
- **Language**: TypeScript with strict typing
- **Styling**: Tailwind CSS (no custom CSS unless essential)
- **Storage**: IndexedDB via custom service
- **Data**: Rebrickable CSV files with manifest management

### Component Architecture
```
src/app/components/
├── home/
├── inventory-detail/          # Unified component for set inventories, missing parts, and loose parts collections
├── loading-overlay/
├── loose-parts/              # Browse and manage loose parts collections
├── sets/
├── settings/
└── collection-inventory/     # DEPRECATED - now using inventory-detail for all inventory views
```

### Service Layer
- `DataService`: CSV data loading and parsing
- `IndexedDBService`: Local database operations
- `StorageService`: User preferences and settings
- `LoadingService`: Application loading states
- `ExportService`: Data export functionality

## 💾 Data Management

### CSV Data Structure
- Large datasets split across multiple files
- Manifest.json tracks file versions and availability
- Memory-conscious loading strategies required
- Always update manifest when modifying data files

### Storage Patterns
- Local IndexedDB for all user data
- No server-side dependencies
- Privacy-first approach (see PRIVACY.md)

## 🎨 UI/UX Standards
